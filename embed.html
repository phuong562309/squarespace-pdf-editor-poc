HOSTED IFRAME

Add PDF Studio to your page

Paste this HTML into a Squarespace Code Block that permits iframes. The editor runs from its separate hosted site. Availability and Code Block support depend on your plan and site settings; installation in a Squarespace tenant has not been verified.

<iframe
  src="https://phuong562309.github.io/squarespace-pdf-editor-poc/"
  title="PDF Studio — annotate and download"
  style="width:100%;height:1500px;border:0;border-radius:12px;"
  loading="lazy"
  allow="downloads"
></iframe>

Use a height suitable for your layout (around 2200px on narrow mobile pages), or allow visitors to scroll inside the frame. Test upload, preview and download on your published page. Browser or site sandbox settings can restrict downloads and PDF viewers.

The URL above is the intended deployment address. The embedded view below works once that site is published; a blank/error frame before deployment does not indicate a successful install.
